# Processo de Onboarding

Passos para início de novos projetos e integração do cliente com a KinSolo.

## Etapas do Kickoff
1. **Formulário de Requisitos**: Preenchimento do levantamento técnico e escopo inicial.
2. **Reunião de Alinhamento (Kickoff)**: Chamada de 30 minutos para validar regras de negócio.
3. **Criação de Acessos**: Envio seguro de tokens, credenciais e acessos a VPS.
4. **Provisionamento do Ambiente**: Configuração dos serviços e início dos testes.

## O Que o Cliente Precisa Fornecer
- Dados de acesso ao provedor de nuvem (Hetzner, DigitalOcean, etc.) ou VPS provisionada.
- Chaves de API das ferramentas envolvidas (OpenAI, WhatsApp API, CRM, ERP).
- Ponto focal técnico ou operacional para tirar dúvidas durante o desenvolvimento.

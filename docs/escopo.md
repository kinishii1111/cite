# Escopo de Serviços

Definição clara do que está incluído e excluído nos projetos da KinSolo.

## O Que a KinSolo Faz
- Automação de fluxos de trabalho usando n8n auto-hospedado ou cloud.
- Integração de agentes inteligentes baseados em LangGraph e Python.
- Deploy, configuração e hardening básico de servidores VPS Linux.
- Webhooks, sincronização de bancos relacionais (Postgres) e APIs REST.
- Pipelines de processamento assíncrono de documentos e dados.

## O Que a KinSolo NÃO Faz
- Desenvolvimento de frontends complexos ou aplicações mobile nativas.
- Suporte a sistemas legados fechados sem documentação ou API pública.
- Gestão contínua de tráfego pago ou marketing digital.
- Atendimento 24/7 ininterrupto com equipe dedicada de plantão.
- Recuperação de dados em infraestrutura mal configurada pelo próprio cliente.
